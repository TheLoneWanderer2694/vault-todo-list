OBS Setup Instructions

  1. Open OBS Studio or Streamlabs OBS.
  2. Add a new source: Select Browser.
  3. Click "Copy OBS URL" at top right and paste into URL.
  4. Set Width: 400, Height: 600.
  5. Check "Refresh browser when scene becomes active".
  6. Done! Edit tasks here; your stream overlay syncs in real-time.
